# 실시간 이미지 분류 (TensorFlow/Keras + OpenCV + PIL)

이 프로젝트는 TensorFlow의 Keras API로 생성한 **Teachable Machine 모델**을 이용해, 웹캠으로 실시간 이미지를 인식하고 예측 결과를 화면에 표시합니다.  
특히 **한글 출력 지원**을 위해 PIL(Pillow)을 활용한 예제입니다.

## ⚙️ 사용된 기술 및 라이브러리

- TensorFlow/Keras
- OpenCV (`opencv-python`)
- PIL (Pillow)
- NumPy
